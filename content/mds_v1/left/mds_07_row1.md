<h2><a id="section1">使用する部品</a></h2>

### キットに含まれるもの

|  品目  |  必要数  |
| ---- | ---- |
|  基板1-1（4キー）  |  1  |

|  ダイオード  |  5  |
|  垂直取付用スペーサー  |  4個  |
|  3.5mmスペーサー（円柱型）  |  2  |
|  3.5mmスペーサー（角柱型）  |  1  |

<h2><a id="section2">基板1-1にはんだ付け</a></h2>

![](/images/mds_v1/left/07/pcb-1-1_back.jpg)

**基板の裏表をよくご確認ください。**

基板1-1の**表面**にダイオード、**裏面**にスイッチソケットをはんだ付けします。

<h2><a id="section3">基板1-2にはんだ付け</a></h2>

![](/images/mds_v1/left/07/pcb-1-2_back.jpg)

基板1-2にスイッチソケットをはんだ付けします。

&nbsp;
&nbsp;

<h2><a id="section4">スペーサーの取り付け</a></h2>

![](/images/mds_v1/left/07/pcb-1-2_cube.jpg)

基板1-2に垂直取付用スペーサーを1個、**3mm**ネジで取り付けます。

![](/images/mds_v1/left/07/pcb-1-1_cube.jpg)

基板1-1の**裏面**、3ヶ所の角に垂直取付用スペーサーを**3mm**ネジで止めます。

![](/images/mds_v1/left/07/pcb-1-1_cylinder.jpg)

基板1-1の**表面**、銅箔で覆われたネジ穴に3.5mmスペーサー（**円柱型**）を**3mm**ネジで止めます。

![](/images/mds_v1/left/07/pcb-1-1_hex.jpg)

基板1-1の**表面**、残り1つのネジ穴に3.5mmスペーサー（角柱型）を**3mm**ネジで付けます。

&nbsp;
&nbsp;

<h2><a id="section5">接続用基板1のはんだ付け</a></h2>

![](/images/mds_v1/left/07/connector-1_parts.jpg)

L型ピンヘッダとピンソケットを用います。

L型ピンヘッダとピンソケットを繋げます。

![](/images/mds_v1/left/07/connector-1_pin.jpg)

L型ピンヘッダを接続用基板に差し込み、はんだ付けします。このとき、ピンヘッダの向きが傾かないようにご注意ください。

&nbsp;
&nbsp;

<h2><a id="section6">基板の取り付け・はんだ付け</a></h2>

![](/images/mds_v1/left/07/connector-1_attached.jpg)

画像のように、メイン基板にピンソケットの先端が刺さるように接続用基板4-2をあてがいます。安定しない場合はマスキングテープで仮止めしてください。

![](/images/mds_v1/left/07/pcb-1-1_attached.jpg)

メイン基板とは反対側のピンソケットが刺さるように、基板1-1を置き、アクリル板と垂直取付用スペーサーを**4mm**ネジで止めます。

ピンソケットをはんだ付けします。

&nbsp;
&nbsp;

<h2><a id="section7">基板1-2の接続</a></h2>

![](/images/mds_v1/left/07/pcb-1-2_attached.jpg)

基板1-1に取り付けた3つの3.5mmスペーサーと、基板1-2を**3mm**ネジで止めます。

基板1-2に付けた垂直取付用スペーサーと、アクリル板を**4mm**ネジで止めます。

&nbsp;
&nbsp;
