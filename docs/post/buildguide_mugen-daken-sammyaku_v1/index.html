注意事項

本キットはご購入者様がご自分で組み立てるキットです。 簡単に組み立てられるように設計しておりますが、必ず組み立てる前にこのビルドガイドをご確認ください。 疑問点があれば、必ず組み立てる前に設計者まで問い合わせてください。取り返しのつかないミスをする前に確認することが大事です。

 

本キットの基板は全てリバーシブルで、左手用か右手用か選んで組み立てることができます。基板の裏表はお間違えの無いよう、よくご確認のうえ組み立ててください。
